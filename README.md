# Buildtrack

A simple CMS (Content Management System) built for construction companies to manage projects, tasks, and team members in one place.

## Overview

Buildtrack helps construction businesses stay organized by providing a centralized platform to:

- Track active and completed construction projects
- Manage project tasks and milestones
- Coordinate team members and assign responsibilities
- Store and retrieve project-related documentation

## Features

- **Project Management** – Create, update, and archive construction projects
- **Task Tracking** – Break projects into tasks, assign owners, and monitor progress
- **Team Management** – Add team members and manage their roles
- **Document Storage** – Attach files and notes to projects and tasks
- **Dashboard** – Get a high-level view of all ongoing work

## Getting Started

### Prerequisites

- Node.js (v18 or later recommended)
- A package manager such as npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Pclaws/Buildtrack.git
   cd Buildtrack
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

## Usage

After starting the server, open your browser and navigate to `http://localhost:3000` (or the port configured in your environment) to access the Buildtrack dashboard.
